This project uses a kaggle dataset that can be found here: https://www.kaggle.com/datasets/hasnainjaved/melanoma-skin-cancer-dataset-of-10000-images

This dataset contains 10,605 images of melanoma skin cancer (both benign and malignant cases). 
The code included in the notebook contains installation code for importing kaggle and downloading the dataset. 

To run this project:
1. Download and/or open "Final_Cecilia_Cary_ML_Final_Project.ipynb". It is a CoLab Notebook ipynb file.
2. Ensure kaggle and the dataset are imported (the code for this is included in the notebook)
3. Run the notebook. This project does not include external API calls or services.
